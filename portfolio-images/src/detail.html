고친 장애 원인 8가지

1

검색창 한 줄로 비공개 글 노출 (SQL 인젝션)

검색어를 SQL에 이어 붙이던 코드를 → 바인딩 변수로 교체

2

목록 화면 10초 이상, 메모리 부족

전체 글을 읽고 자바에서 자르던 방식을 → DB에서 10건만 조회 + 인덱스

3

목록 한 번에 쿼리 11번 (N+1)

글마다 댓글 수를 따로 세던 것을 → 집계 조인 1번으로

4

오류가 쌓이면 사이트 전체 멈춤

예외 시 커넥션이 반환되지 않던 것을 → 스프링 트랜잭션이 관리

5

주소 한 글자로 500 에러 화면

잘못된 페이지 번호를 → 400 안내 화면 + 범위 자동 보정

6

빈 제목·작은따옴표 제목에서 오류

검증 없던 입력을 → 입력값 검증 + 등록은 POST만 허용

7

검색어에 넣은 스크립트가 실행됨 (XSS)

그대로 출력하던 화면을 → 자동 이스케이프 템플릿으로

8

화면 하나 고치면 다른 곳이 깨짐

JSP에 섞여 있던 자바 코드를 → 서비스 계층으로 분리
